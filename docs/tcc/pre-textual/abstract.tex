\begin{resumo}[Abstract]
\begin{otherlanguage*}{english}
\OnehalfSpacing
Hands-on practice in operating systems, especially in the Linux ecosystem, is essential in computing education. It has traditionally relied on virtual machines or dual-boot installations, which demand significant hardware resources, run into firmware virtualization incompatibilities, consume class time with technical support and are constrained by the lack of administrative privileges in campus laboratories. Browser-only simulators, on the other hand, are unsuitable for formal assessment, since students can inspect or tamper with the grading routines through the browser developer tools. This work presents the design and implementation of a hybrid educational platform for teaching and assessing operating systems practice. In the browser, a Linux terminal simulator built with TypeScript, featuring an in-memory virtual file system, responds to commands instantly. On the server, a Go service handles authentication, academic records and tamper-proof grading. The platform offers three access tiers: public, for open study without registration; student, linked to the institutional record, with guided tracks and timed exams; and teacher, with class management, exam administration and content authoring: editable modules, an exercise bank with reusable scenarios tested before publication, and fixed or level-based randomized exams. During exams, a WebSocket telemetry channel feeds a real-time teacher dashboard, and exams also include in-class access codes, a help queue with private or group replies, developer tools and tab-switch detection, and an audit timeline that keeps the final grading decision with the teacher. To withstand laboratory network outages, an offline contingency protocol relies on encrypted assertions, local browser storage and later reconciliation through signed bundles. Validated by an automated test suite, the solution reduces extraneous cognitive load, makes better use of class time and strengthens assessment integrity at the Federal University of Technology -- Paraná, Guarapuava Campus.

\vspace{\onelineskip}
\noindent\textbf{Keywords:} operating systems; Linux; web simulation; WebSockets; offline contingency; practical assessment.
\end{otherlanguage*}
\end{resumo}
