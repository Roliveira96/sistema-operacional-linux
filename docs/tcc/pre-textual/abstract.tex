\begin{resumo}[Abstract]
\begin{otherlanguage*}{english}
Practical learning in Operating Systems (OS), particularly within the Linux ecosystem, constitutes a foundational pillar in computer science and software engineering education. Traditionally, laboratory sessions rely on local Virtual Machines (VMs) or dual-boot setups, which introduce severe operational friction: high hardware resource consumption, BIOS/UEFI virtualization incompatibilities, instructional time lost to technical troubleshooting, and privilege restrictions in campus laboratories. Conversely, purely client-side browser simulators are vulnerable to source code inspection and state tampering via browser Developer Tools (DevTools) during formal summative assessments. This Undergraduate Thesis presents the design and implementation of a hybrid reactive educational platform for hands-on learning and practical assessment in Operating Systems. The decoupled architecture pairs a high-fidelity client-side Linux/POSIX simulation engine in TypeScript and React --- featuring an in-memory Virtual File System (VFS) with zero execution latency --- with a high-performance server-side backend developed in Golang, utilizing Gin-Gonic and GORM. The platform establishes three hierarchical access tiers: Public (unrestricted autonomous experimentation without authentication barriers), Student (institutional registration, enrolled classroom tracking, guided exercises, and timed evaluations), and Teacher (full pedagogical governance, assignment authoring, and real-time lab oversight). A bidirectional real-time telemetry pipeline via WebSockets (WSS) powers an interactive Teacher Cockpit for active cohort supervision. The exam lifecycle integrates dynamic classroom check-in tokens, a synchronous help queue (``virtual hand'') supporting private replies and broadcast announcements, integrity telemetry detecting tab defocus or DevTools usage, and a forensic audit timeline preserving instructor authority for formative grade overrides. To withstand campus network failures, a resilient offline contingency protocol leverages encrypted assertion envelopes (HMAC-SHA256 via Web Crypto API), local persistence via IndexedDB, and asynchronous reconciliation through tamper-evident signed bundles (\texttt{.proof}). Validated against an automated test suite of over 750 test cases covering POSIX compliance and industry scenarios, the platform eliminates extrinsic cognitive load, optimizes active instructional time, and ensures evaluation integrity at UTFPR Guarapuava Campus.

\textbf{Keywords:} Operating Systems. Linux. Web Simulation. WebSockets. Offline Contingency. Practical Assessment. UTFPR.
\end{otherlanguage*}
\end{resumo}
